    Number systems

    Edited Sep 22 · select any text to Ask AI

    Computers store everything as binary, base 2, where each place is a power of two. Decimal 13 is 1101 in binary: 8 + 4 + 0 + 1.

    DecimalBinaryHex
    101010A
    131101D
    2551111 1111FF

    Hexadecimal groups binary four bits at a time, which is why 255 fits in two hex digits. Convert by grouping from the right, then read each group as one hex digit.

    Octal groups three bits at a time and was common on older machines. Prof mentioned it will appear on the midterm as a conversion item.
