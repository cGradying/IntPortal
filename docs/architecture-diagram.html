PUPSISPortal Architecture

Native macOS app, single process — headless SIS session, local storage, native SwiftUI, and a local-only AI layer

Headless, native

  • • The real SIS site is never shown
  • • A hidden WKWebView holds the session
  • • Everything on screen is drawn by SwiftUI
  • • Works offline from cache after first sign-in

AI, local-only

  • • Opt-in, off by default
  • • Ollama for chat + embeddings
  • • llama.cpp for grounded RAG answers
  • • No cloud provider, ever — nothing leaves the Mac

Your data, your account

  • • Credentials only in the Keychain
  • • Cached schedule/grades/notes: 0600
  • • Own account only — no other student's data
  • • Export to Calendar.app or Google, your choice
