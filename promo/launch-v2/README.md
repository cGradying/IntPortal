# IntPortal launch video v2 — "Isko's Day"

A 32-second, 150 BPM launch film for IntPortal. One school day (dawn → night) plays out behind every
scene while **Isko**, the app's own student mascot, walks you through the portal, the iPhone app, the
Mac app, the Rooms (themes) and — next — every campus.

## How it is put together

```
promo/launch-v2/
  tools/cues_def.py         the clock: scenes, ~150 sound/visual cues, narrator + blip lines (single source of truth)
  tools/audio/*.py          score, SFX, narrator, mix → audio/master.wav  (also analyze.py: loudness / kick grid / spectrum)
  tools/bake_wordmark.mjs   bakes "IntPortal" (Pixelify Sans) into a bitmap for the voxel assembly
  tools/qa_sheets.sh        contact sheets of a render, one tile per beat
  cues/cues.json            generated by cues_def.py
  composition/              the Hyperframes project: index.html, compositions/*.html (one per scene), assets/lib/*.js
```

`cues_def.py` writes `cues/cues.json` (read by the audio build) and `composition/assets/cues.js` (read by the
animation), so a visual impact and its sound cannot drift apart. Everything is a pure function of time (seeded
PRNG, no clocks, no `Math.random`), so a render is reproducible.

### Rebuild

```bash
python3 tools/cues_def.py                                      # clock → cues.json + cues.js
pip install -r tools/requirements.txt                          # + ffmpeg on PATH
# Kokoro TTS model (int8) from https://github.com/thewh1teagle/kokoro-onnx/releases  →  ~/models/kokoro/
#   kokoro-v1.0.int8.onnx, voices-v1.0.bin      (override with KOKORO_MODEL / KOKORO_VOICES)
python3 tools/audio/build_audio.py                             # → audio/master.wav (−14 LUFS)
cp audio/master.wav composition/assets/audio/master.wav
cd composition && npx hyperframes lint && npx hyperframes render -f 60 -o ../launch-v2.mp4
```

The published master swaps the renderer's audio for `master.wav` (AAC-LC, −0.4 dB so the encoded true peak stays
under −1 dBFS): `ffmpeg -i render.mp4 -i audio/master.wav -map 0:v -map 1:a -c:v copy -af volume=-0.4dB -c:a aac -b:a 256k out.mp4`.

## Design language (all of it is visible in the frame)

- **Brand:** void `#07050A`, obsidian portal blocks, the dithered swirl ramp `#170509 → #540A1C → #941C30 → #CCA128 → #FAEBB3`,
  gold `#F5B227`, maroon `#6D0E1F`, Pixelify Sans display type, stepped (pixel-notched) corners, stamps that "thunk".
- **Isko:** the app's canonical 14×20 student (white PUP polo, maroon collar, gold lanyard + ID), extended with run / jump /
  cheer / sleepy poses and extruded into a 3D voxel figurine. The jeepney and the campus scene are the app's own sprites.
- **iPhone look:** the "Night" Room (charcoal `#19191c`, gold `#f5b227`), Island/Glance, five-tab bar, grade stamps, pull-to-sync.
- **Rooms:** the real palette values (PUP Maroon, Night, Astra Moon, Sakura, Matrix, Dracula, Nord, Tokyo Night).

## Honest notes

- The iPhone/Android app lives in a **private** repository. Nothing from it is copied here as source. What appears is what is
  visible on screen (the mascot's sprite grid, palette values, the look of the UI) rebuilt from scratch as video markup in
  `composition/assets/lib/ip-ui.*`, and `ip-core.js` re-implements the Room colour derivation from the palette values. The
  video says "iPhone & Android coming".
- All names, courses and grades on screen are **sample data**. Nothing is a real student record.
- "Local by default": AI runs on the machine unless you bring your own key. "Every campus next" is the roadmap; only PUP
  Sta. Mesa is connected today.
- Unofficial app by a PUP student. Not affiliated with PUP.
- I could not listen to the audio. It was verified by measurement (loudness, true peak, kick vs the beat grid, spectral balance,
  narrator/blip timing vs the visual cues), not by ear — give it a listen before you post.
- `hyperframes check` reports layout/contrast findings on intentional layering (exploded UI layers, the assistant panel over the
  Mac window, cross-scene transitions, the dimmed backdrop). They were reviewed on the rendered frames; `lint` is clean.
