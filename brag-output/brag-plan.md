# Brag Plan: IntPortal

## What is this app?
IntPortal is a native macOS app that signs into the PUP SIS headlessly, so the slow web portal is never shown, and renders your own schedule, grades, notes, a local AI assistant (IntAssis) and spaced-repetition quiz decks as pixel-forward native UI.

## The angle
"The Portal and the Registrar" (DESIGN.md's own north star). The video *is* the product's story: land in the void, a pixel portal assembles block by block, the camera dives into the maroon→gold swirl, a gold-white flash, and you are inside the registrar's window *using* the app: cursor, stamps, now-line, typing, streaks. Every frame is IntPortal's own grammar: void black, obsidian blocks, maroon menu field, Pixelify Sans identity type over Source Sans 3, stepped pixel corners, rubber stamps.

## Hook (0-3s)
Void + drifting pixel motes. Obsidian blocks drop in one by one and assemble the portal frame; "STEP / THROUGH." slams in on the beat; the swirl ignites on a strong cue.

## Key moments
- Warp: camera dives into the dithered swirl, pixels grow chunky, gold-white flash (beat-locked to the 5.26s strong cue).
- Schedule: week grid fills one class per beat, gold now-line sweeps in, cursor clicks COMP 001, an "ONLINE" rubber stamp slams (beat-locked 8.42s), export toast.
- Today + IntAssis: day timeline with "Free · 6h" gap, assistant panel opens, `/rag summarize my C note` is typed, answer streams with source chips. "Never leaves your Mac."
- Grades: GPA counts up, trend line draws, rows land on beats. Quizzes: isometric study map towers grow, streak heatmap fills, then Registrar Night (dark theme) flips on.

## Outro / punchline
Portal + wordmark: **IntPortal**, "Your PUP class schedule, as a native Mac app." v1.7.0 · macOS 14+ · github.com/cGradying/IntPortal. Unofficial, not affiliated with PUP.

## User flow worth showing
Enter (portal -> signed in) -> key action (open week, stamp a class online, ask IntAssis) -> result (grades/GPA, study map, streak).
